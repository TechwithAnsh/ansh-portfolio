# Ansh Kumar — Portfolio Website

A responsive personal portfolio for Ansh Kumar, BCA (AI & Data Science), K.R. Mangalam University.

## Deploy with GitHub Pages
1. Create a new public repository named `ansh-portfolio` on GitHub.
2. Upload `index.html` (and this README if desired) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. The public URL should be `https://techwithansh.github.io/ansh-portfolio/` if the GitHub username is exactly `TechwithAnsh`.
7. Open the URL and test it on phone and laptop before adding it to the assignment.
